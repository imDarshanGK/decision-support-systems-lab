# Experiment 01 - Decision Tree

## Decision Support Systems Lab

### Experiment Title
Construct a Decision Tree for a Business Scenario

### Aim
To construct and analyze a Decision Tree model for a business decision-making scenario.

### Problem Statement
A bank wants to automate its Loan Approval Decision using:

- Age
- Annual Income
- Credit Score
- Employment Status

The Decision Tree predicts whether the loan should be **Approved** or **Rejected**.

### Assignment
Using the Bank Marketing Dataset:

- Build a Decision Tree classifier.
- Compare Entropy and Gini criteria.
- Report classification accuracy.
- Visualize the Decision Tree.
- Identify the most important features influencing the decision.

### Dataset
[UCI Bank Marketing Dataset](https://archive.ics.uci.edu/dataset/222/bank+marketing)

### Files

- `decision_tree.py` – Decision Tree implementation
- `assignment_bank_marketing.py` – Bank Marketing assignment
- `bank-full.csv` – Dataset used for the assignment

All programs are implemented in Python.
